## 0. 전제 — 배포 조건이 강제하는 결론

3주 내 실수조 배포. 조건과 그로부터의 논리 사슬:

```
수조 수질 미지  +  표적 물체 선택 불가  +  실수조엔 GT depth 없음
  → 정책은 물체·수질 분포에 일반화돼야 한다     (Stage 4 + 수질 DR = 배포 요건)
  → 물체·수질이 에피소드마다 바뀌는 학습이 성립하려면
  → 보상·관측이 물체·수질 불변으로 정규화돼야 한다  (정규화 = 임계 경로)
  → 배포 관측(vox_actor)을 만들 depth를 카메라에서 추정해야 한다 (Stage 3 = 센서 문제)
```

따라서 Stage 2/3/4는 별개 단계가 아니라 **하나의 배포 트랙**이다.

실기 센서: 카메라 640×480 · DVL(pose + 고도 + ego-motion) · 소나(수조 잔향 심각
→ 조밀 depth 부적격, 스칼라 앵커 후보로만 잔류).

## 1. 보상·관측 정규화 — (A) 채택, (B) 연기

### 채택: (A) voxel별 기하 정규화

```
q*(v)      = exp(−μ · max(ψ_min − r_v, d_near))     r_v = voxel의 물체중심 거리
progress   = (1/N) Σ_v  Q_vol(v) / q*(v)             Q_vol = max 누적 (기존 유지)
관측 ch2    = Q_vol(v) / q*(v)                        보상과 동일 정규화 공유
```

근거:
- 스칼라 `Q_sat = exp(−μψ_min)`의 방사형 왜곡 제거 — 근측면은 비율이 1을 넘어
  clamp에서 정보가 파괴되고(접근 유인 소실), 원측면은 상한 0.92에 갇혔다.
- **수질 불변**: 정규화값 = exp(−μ(d_best−d_min))이므로 최댓값 1.0이 어떤 μ에서도
  달성 가능 → 임계값·커리큘럼·성공률의 **눈금이 수질과 무관**해진다. 난이도가
  같아진다는 뜻이 아니다 — μ가 크면 거리 초과의 벌이 지수적으로 커지는데 그건
  의도된 물리다. 이 불변성이 없으면 수질 DR 하에서 같은 행동이 μ에 따라 다른
  점수를 받아 critic에 "정책 탓 아닌 분산"이 실린다(ev 붕괴 전례 있음).
- 보상 형태·스케일이 유지되어 기존 보정(k_c=20, c_step=0.02, bonus=10,
  적응형 커리큘럼)을 재사용한다.
- 물체별 상한 차이 중 **가려짐 성분**은 남는다 — 적응형 커리큘럼(성공률 게이트)이
  평균적으로 흡수. 완전 해소는 (C) 가시성 프리컴퓨트(연기, §8).

### 구현 완료 + 실측 검증 (2026-09-03)

**전환 전 증거** — Stage 2 최종 평가(단일 rock, 25결정)를 같은 결정 수에서
다시 재니 학습 정책이 랜덤을 명확히 이겼지만(결정 7회 cov_q 0.550 vs 0.385,
성공률 0.96 vs 0.52), **이득의 출처가 시점 선택이 아니었다**:

| 결정 7회 시점 | cov_q | cov_bin(본 표면) | psi | phi |
|---|---|---|---|---|
| 학습 정책 | 0.550 | **0.520** | 1.02 (하한) | 80.0° (상한) |
| random | 0.385 | 0.482 | 2.62 | 43° |
| orbit | 0.394 | **0.524** | 2.55 | 30° |

표면 관측량은 고정 orbit과 같고, 품질비 `cov_q/cov_bin = 1.083 > 1`. 전역
`Q_sat`으로 나눈 뒤 **합산-후-clamp**라 1을 넘은 근측면 voxel의 초과분이 못 본
voxel을 상쇄했다. 정책은 "시점 박스의 모서리(psi 하한 + phi 상한)로 가서 멈추기"를
학습한 것이다.

**전환 후 회귀 테스트** — `evaluate_nbv.py`에 `approach` 베이스라인을 추가했다
(psi를 하한까지 밀고 고착 = 위 학습 행동의 순수형). (A) 적용 후 8env×16ep×15결정:

```
정책        cov_q  cov_bin  성공률   psi평균
orbit       0.602   0.676    0.38    1.48
random      0.539   0.582    0.06    1.55
hold        0.225   0.269    0.00    1.61
approach    0.185   0.189    0.00    1.06   ← 근접 고착이 최하위
```

근접만으로는 정지보다도 못하다 = **구멍이 닫혔다**. 부수 확인: psi 1.0 m에서는
화각(HFOV 47.2°/VFOV 36.3°)상 0.87×0.65 m만 보여 물체가 프레임을 넘치므로,
접근이 오히려 표면을 잃는다(approach cov_bin 0.189 < hold 0.269).
`approach`는 앞으로 상설 회귀 지표다 — 이것이 orbit을 넘으면 정규화가 새는 것.

주의(기록): 현재 고정 수질(IB, μ≈0.1)에서는 `cov_q ≈ 0.89·cov_bin`으로 품질
항의 변별력이 약하다. 즉 지금 과제는 사실상 "표면을 최대한 보라"다. 수질 DR을
켜면(μ 상승) 거리 항이 지수적으로 세져 변별력이 생긴다 — 의도된 순서다.

### 연기: (B) NBUV ln-이득 (`Σ_v ½ln(1 + q/Q)`)

논의로 확정된 사실(연기하되 기록):
- step_1의 "NBUV 모사 실패"는 정식의 실패가 아니라 **절반 구현**이었다: Eq.20(sum
  누적)만 가져오고 Eq.24(log 이득)를 빠뜨렸다. 로그 없는 sum은 무한 누적 + 재방문
  보상 비체감(응시 채굴 유인)으로 구조적으로 못 쓴다. 당시 교란 4건(수질 파라미터
  전치, surface_mask tsdf≤0 버그, Q_sat 불일치, q 잡음 모델 부재)이 겹쳐 진단이
  "sum이 문제"로 잘못 내려졌고 max로 후퇴했다. max는 물체 1개·수질 1개에서만
  공짜인 응급처치였다.
- (B)의 실질 우위는 종료 조건이 아니라(voxel별 정규화 + 임계값으로도 가려짐 한도
  내에서 종료 조건 성립 — 2026-09-02 논의에서 정정) **q에 담기는 물리**다:
  backscatter shot noise(원거리 페널티 e^{−2μd}/B), depth 오차 채널
  q_geom ∝ 1/(AbsRel·d)², 재방문의 융합 가치(σ²/N).
- (B)는 TRIDENT 불요(q는 해석적·센서 불가지론적), 공간 인프라는 (A)와 동일 —
  바뀌는 것은 voxel 장부의 기입 규칙(max→sum)과 이득 함수(선형→log)뿐.
- 연기 사유: 보상 스케일 전면 재보정 + 커리큘럼/종료 재정의 = 검증 사이클 1회
  추가. 시한 밖. 배포 후 1순위 전환 후보.

| 장면별 스케일 보정 후 | 0.130 | **오차의 2/3가 전역 스케일/시프트** |

| 스케일 편향 | 중앙값 1.14, CV 0.25 | 융합으로 평균화 안 됨 |
| uncertainty 출력 | 97.6% zero, ρ≈0.04 | **기각 확정** — TSDF 가중 사용 불가 |
| 실수조 성능 | 미지 | sim 도메인 측정이므로 |

### 결정: TRIDENT + DVL scale anchor

앵커의 용도는 정확히 한 곳 — **배포(및 ②b)의 depth 전처리, TSDF 융합 직전**:

```
D̂ = TRIDENT(rgb)                      조밀하나 장면별 스케일 ŝ 미지
ŝ  ← (i) 고도 대조: DVL 바닥거리 h vs 바닥 픽셀들의 D̂ 중앙값
    (ii) ego-motion 시차: DVL 적분 이동량 b vs 단안 시차 이동량 b̂
D  = ŝ·D̂  (에피소드 내 EMA 필터)  →  TSDF  →  vox_actor
```

효과: 평균화되지 않는 지배 성분(스케일)을 소거 → 실효 AbsRel 0.13~0.16 전망.
학습·보상·②a와 무관하며, DVL의 pose 피드백 역할과도 별개 용도다.

TRIDENT의 지위: **임계 경로의 전제가 아니라 "배포 센서 후보 + 자격시험 응시자"**.
학습(teacher), ②a, distillation 어디에도 불필요하고(전부 GT/파라메트릭), 배포일에
카메라→depth가 필요해서 쓴다. 다른 단안 모델로 교체해도 계획 불변.

### 기하 재설정 (재학습에 합류, **2026-09-03 확정**)

앵커를 써도 ψ≤4.5 m는 산술적으로 허용선 밖(0.13×4.5=0.59 m). 후보:

```
ψ 1.0 ~ 2.5 m,  voxel 10 cm (trunc 동일)
→ 대표거리 1.7 m에서 σ ≈ 0.22 m ≈ 2 voxel, 물체(≤1.1 m)가 ~10 voxel
→ 산출물 등급 = "거친 형상 파악" (정밀 재구성 아님 — 3주의 정직한 목표)
```

원리: 물체를 가로지르는 voxel 수 = (1/AbsRel)·(S/d). GT depth일 때만 voxel이
자유 변수였다.

### ⚠ 제약 (2026-09-03 소스 확인): 물체 다양성 = min(num_envs, 풀 크기)

`spawn_multi_usd_file()`은 리스트의 **모든** 자산을 템플릿 프림으로 스폰한 뒤
env i에 `proto[i % N]`을 복사한다(`wrappers.py:114`). 이 배정은 **씬 생성 시
한 번뿐**이고 리셋으로 바뀌지 않는다. 따라서:

- 128 env로 학습하면 700개가 아니라 **128개** 물체만 등장한다
- 초과분은 등장하지 않으면서 startup USD 로딩 비용만 얹는다(700개 = 14 GB)
  → `mesh_pool_limit` 기본값을 **num_envs로 자동 제한**하도록 배선함
- train 풀은 셔플 순서를 유지한다 — 알파벳순이면 앞 N개가 한 가족
  (`3D_Dollhouse_*` 등)에 몰려 다양성이 더 줄어든다

**대응 순서**: ① 우선 가능한 만큼의 env로 학습하고 **홀드아웃으로 실측**한다.
② 홀드아웃 격차가 크면 그때 env당 메쉬 스택(K개 사전 스폰 + 리셋마다 가시성
토글)을 만들어 K×num_envs로 늘린다. 지금 ②를 먼저 만드는 것은 측정 없는
투자다.
- 수질 DR: `jerlov_dr_enabled=True`, 프리셋 IB~1C (5C는 ψ_max에서 아무것도 안
  보여 학습 자체를 무산시킴)

## 5. 비상계획 — Privileged Teacher–Student Distillation

사족보행 sim2real(Lee 2020, RMA)의 이식. **센서 불가지론적**으로 정의한다.

```
P1 Teacher   특권 RL (GT depth TSDF + GT pose 관측) → teacher.pt   [= 이번 재학습]
P3 Student   같은 프레임에서 이중 관측:
               teacher 스트림: GT 융합 TSDF        → 정답 액션 라벨 (greedy)
               student 스트림: 오염 융합 TSDF       → student 입력
             오염 = 파라메트릭 주입 (TRIDENT 루프 불요):
               depth 스케일 편향 LogNormal(앵커 후 CV 0.05~0.10보다 넓게 — 앵커
               실패 보험), 잡음∝d, pose는 step_2 dvl_realism 패턴, μ̂ ×U(0.7,1.4)
             BC(~20K 결정) → DAgger 3~5회 (covariate shift 대응)
             손실 = pre-tanh mu MSE. RL 손실 없음 (PPO 불안정성 전체를 우회)
             비용 ~3일. 이중 관측 env의 절반은 ②a가 어차피 요구하는 코드.
```

발동: ②a/②b 결과 열화 15% 이상. 성공 기준(사전 선언): 홀드아웃에서
student(오염)가 [teacher(GT) − teacher(오염)] 갭의 60% 이상 회복 + random 유의 우위.

**진단표 (실패해도 다음 1주의 방향이 측정으로 정해짐):**

| 관찰 | 해석 | 조치 |
|---|---|---|
| student(오염) ≈ teacher(GT) | 잡음이 정보를 파괴 안 함 | 배포 진행 |
| 부분 회복 | 분포 적응은 됨 | recurrent student (GRU = 경량 RMA: 이력에서 잔여 오차 latent 암묵 추정) |
| student(오염) ≈ teacher(오염) | **imitation gap** — 오염 관측에 정보 자체가 없음 | distillation 포기, 기하 재설계 격상 |

RMA와의 관계: DVL 앵커 = 스케일 latent의 **명시적** 추정기, RMA 모듈 = 같은 것의
**암묵적** 추정기. 시한 내엔 명시적 앵커 우선, 경량 RMA는 recurrent student의
부산물로만. 정식 RMA(특권 latent 입력 + 2단 학습)와 이미지 전용 recurrent
student(TSDF 포기)는 각각 연기·최후 fallback.

산출물: student.pt(발동 시) 또는 teacher.pt가 **곧 배포 아티팩트** — step_2 deploy
패턴으로 TorchScript export.

## 6. 전체 파이프라인 (학습 → 배포)

```
P0 준비      GSO 700/91 · 수질 DR · (A) 정규화 · 새 기하        [코드 완료/진행]
P1 Teacher   특권 RL 재학습 1회 (다변수 합류: 물체+수질+정규화+기하)
P2 관문      ②a 허용선 → ②b 자격시험
P3 조건부    distillation (§5)
P4 통합      TorchScript · ROS2 노드 3종(trident+anchor / tsdf / policy 0.2 Hz)
             + 기존 DP 컨트롤러 · Gazebo sim2sim (step_2 확립 경로)
P5 실수조    캘리브레이션(카메라 intrinsics, 수조 μ 1회 측정)
             → shakedown (hold 정지 유지, DVL pose)
             → 베이스라인 실측 (스크립트 orbit, random)
             → 정책 → 기지 형상 물체로 오프라인 coverage 평가
```

주차 배정: 1주 = P0~P2 (+필요시 P3) · 2주 = P4 + 수조 shakedown · 3주 = P5.

**P4 주의**: TSDF 노드는 `env_reward`의 융합 로직을 **복사하지 말고 같은 모듈을
import**할 것 — 융합부를 순수 함수로 분리하는 소규모 리팩토링 선행.
(step_2 `sync_vendor.sh`의 복제본 드리프트 + 정규식 버그 전례.)
