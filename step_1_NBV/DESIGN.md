# step_1 — Quality-aware next-best-view planning (design notes)

Reinforcement-learning next-best-view (NBV) planning for a camera-equipped
underwater vehicle observing an unknown object. This document records the
problem formulation, the design decisions and why they were made, and the
evaluation protocol. Day-to-day working notes live elsewhere.

## 1. Problem

An agent moves a camera on a sphere around an unknown target and must choose,
step by step, where to look next. On land this is a coverage problem. Underwater
it is not: light is attenuated on the way to the object and back, so a
geometrically ideal viewpoint can return an image with no usable information.
The objective is therefore **observation quality**, not surface coverage.

The task is formulated as a POMDP — the object geometry is never observed
directly, only through images — and solved with PPO. Baseline planners are
implemented in the same environment so that all methods see identical episodes.

## 2. Environment

| Item | Value |
|---|---|
| Simulator | Isaac Sim 5.1 + IsaacLab, OceanSim underwater renderer |
| Target | Rock-like meshes; pose randomized per episode |
| Camera range | 1.0 – 4.5 m from target |
| Step | Δθ, Δφ = 15°, Δψ = 0.20 m |
| Episode | 50 decisions |
| Map | TSDF, 40³ voxels, 5 cm voxels, truncation = voxel size |

### Observation

| Component | Shape | Content |
|---|---|---|
| Image history | (6, 84, 84) | last 6 grayscale frames (actor) / depth frames (critic) |
| Pose | 3 | spherical coordinates (θ, φ, ψ) of the camera |
| Voxel grid | (3, 40, 40, 40) | ch0 unknown · ch1 free · ch2 accumulated observation quality |

The voxel grid is the agent's belief-like state. ch2 is what distinguishes this
environment from a binary-coverage NBV environment.

### Action

Six discrete moves: ±θ, ±φ, ±ψ.

## 3. Observation-quality metric

Each camera ray to a voxel is scored with a single-pass Beer–Lambert term

```
q(v) = exp(−μ · d)
```

where `μ` is the (channel-averaged) attenuation coefficient of the current water
and `d` the camera–voxel distance. The renderer applies attenuation once
(camera → object), so the metric is deliberately one-way to match it.

**Accumulation.** Each voxel keeps the **best** quality it has been observed
with, `Q(v) = max(Q(v), q(v))`. An earlier version summed Fisher-information
terms (after NBUV, CVPR 2016); summing rewards revisiting the same view and let
the metric grow without bound, so it was replaced.

**Coverage.** `coverage_q = mean over ground-truth surface voxels of Q(v)`.
With `μ` fixed at 0.217 and a minimum range of 1 m, the attainable maximum is
≈ 0.805; the success threshold is set to 0.65 (≈ 81 % of that).

**Which voxels accumulate.** Quality is accumulated for every voxel a ray has
passed near (`weight > 0`), *not* only for voxels the TSDF has classified as
surface. This was a deliberate correction: with a 5 cm voxel, a ray that passes
the voxel centre before hitting the mesh produces `sdf > 0` and the TSDF labels
a true surface voxel as free space. Requiring the surface label blocked quality
accumulation on 37 % of observed surface voxels and capped `coverage_q` around
0.48. Dropping the requirement is also closer to the original NBUV formulation,
in which the quantity of interest is observed information, not reconstruction
confidence.

## 4. Water domain randomization

Water optics are randomized per episode over six **Jerlov water types**
(IB, II, III, 1C, 3C, 5C). Per-channel attenuation and backscatter parameters
for each type are computed with the revised underwater image formation model of
Akkaynak & Treibitz (CVPR 2018) at the scene depth and reference range
(`utils_NBV/jerlov_presets.py`, generated by `utils_NBV/calculator.py`). The
policy therefore never sees one turbidity only.

## 5. Reward

```
r = k_cq · Δcoverage_q            # quality gain this step
  − k_x  · distance_moved         # small; see note
  − c_step                        # per-step cost
  − k_still · [Δcoverage_q < ε]   # stall penalty
  + bonus · [coverage_q ≥ 0.65]   # success
```

Two constraints learned the hard way:

- The movement penalty `k_x` must stay small. A large value teaches the agent to
  approach once and then wait.
- `c_step` must be much smaller than the largest achievable per-step quality
  gain, otherwise the agent stops moving altogether.

## 6. Policy and training

- Actor: image encoder + 3D-CNN over the voxel grid + MLP on pose, fused and
  followed by an LSTM (GenNBV-style multi-source embedding, `algorithm/algo_UW_NBV.py`).
- PPO with a KL target (0.02) and entropy coefficient 0.03. Without the KL
  target an otherwise identical run collapsed at 51 k steps; with it a
  transient collapse at ~125 k steps self-recovered through early stopping.
- 4 parallel environments; two Isaac Sim processes cannot share one GPU.

## 7. Evaluation protocol

All planners are evaluated by one harness (`evaluate/evaluate_recon.py`) in the
same quality-aware environment, with the same termination rules:

| Rule | Condition |
|---|---|
| success | `coverage_q ≥ 0.65` |
| stall | `Δcoverage_q < 0.01` for 5 consecutive steps |
| timeout | 50 steps |

Object pose and initial camera pose are fixed in evaluation mode so that water
type is the only deliberately varied factor.

Compared planners (`evaluate/run_eval_all.sh`, `run_eval_jerlov.sh`):

| Planner | Type | Notes |
|---|---|---|
| Manual orbit | scripted | fixed-elevation circle |
| ScanRL | learned (DQN) | binary coverage reward |
| GenNBV | learned (PPO) | binary coverage reward |
| Ours, fixed water | learned (PPO) | quality reward, μ = 0.217 |
| Ours, Jerlov DR | learned (PPO) | quality reward, randomized water |

Two sweeps: (a) fixed water, μ = 0.217, coverage-vs-step AUC; (b) 6 Jerlov
types × 10 episodes per type, per-type coverage AUC — i.e., does water
randomization actually help across turbidities.

Each episode writes `step_log.csv`, per-step coverage histories, an external
view video and the reconstructed mesh (`recon_output/<run>/ep_XXX/`).

## 9. Known limitations

- The quality metric is a distance-attenuation heuristic, not an expected
  information gain over an explicit belief. Extending toward
  information-theoretic view selection is the natural next step.
- Sonar is not modelled; the environment is optical only.
- Success threshold and `q_sat` are tied to a fixed `μ`; under water DR the
  attainable maximum varies with water type.
